# 🧠 PsyTrace — Psychological Profiling System

**PsyTrace** is an automated system for calculating the Integrative Coefficient (IC) of digital identity based on the analysis of users' textual digital footprints.

> 📝 **Research tool.** Available upon request for academic purposes.

---

## 📋 About

PsyTrace analyzes texts from social networks, reviews, and other digital sources, calculating **10 psychological features** and aggregating them into an **Integrative Coefficient (IC)** on a scale from 0 to 100.

### 🧪 Validation
- **Sample:** 2,657 users, >43,000 texts
- **Reproducibility:** 99.8%
- **Methods correlation:** r = 0.990
- **Population norms:** M = 46.4, SD = 12.1

### 📊 Integration Levels
| Level | IC Range |
|:---|:---:|
| 🔴 Disintegrated | < 35 |
| 🟠 Emerging | 35–45 |
| 🟡 Differentiated | 45–55 |
| 🟢 Integrated | 55–65 |
| 🟣 Integrative | > 65 |
